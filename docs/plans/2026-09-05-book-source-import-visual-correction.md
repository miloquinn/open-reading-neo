## 视觉修正结果

- panel 删除步骤提示、引导段落、重背景预览卡和重复的底部取消按钮；复用既有 BookSourcePill。关闭放在标题栏，原责任确认保留，完整声明从“书源使用说明”展开。
- route 用最大高度约束替代固定高度，桌面最大宽度收窄为480。内容多时滚动，内容少时收缩；没有改下载/保存/取消逻辑。
- `tool/preview_book_source_import.dart` 同时输出整屏与真实组件边界渲染，位于 `.omx/book-source-import-revised-previews/`，避免用图片后处理掩盖布局问题。
- 用户尚未验收新视觉，不把内部截图检查称作用户认可。

## 新增反馈：导入后长期停在解析

用户明确触发点为导入后解析，非手动去重或规则切换。当前缺少该次书源链接/文件，已请求用于复现，不能声称实际长等待已修复。

只读合成计时（本机，非真机数据）：
- 1000个书源约5.1MB：后台完整解析约140ms。
- 2000个书源约57.6MB，大段脚本文本和字符串JSON规则：完整后台约1227ms；独立解码约670ms，兼容性扫描约529ms。
- 10000个书源约15.7MB：后台完整约499ms。
- 独立AOT去重基准：10000候选5000重复组，构建约42ms、去重约21ms；未发现两两比较的平方级算法。

基准只能缩小调查范围：提示文字不意味着去重本体慢；现有模拟未复现用户的长期等待。因此没有凭这些数据修改去重算法、跳过兼容检查或宣称提速已解决。待取得用户文件后继续检查具体输入、运行设备与真实分段耗时。

可复现工具：`tool/benchmark_source_import.dart` 和 `tool/benchmark_source_dedupe.dart`；本轮新增两者，无生产后端修改。
