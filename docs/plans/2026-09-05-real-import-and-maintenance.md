# 实际书源导入与整理完善

用户提供 `/Users/xiaoyuan/work/书资源` 作为真实测试语料，并要求缩短导入解析/查重等待、完善书源整理的UI和逻辑。原始资源只读，不联网探测这些语料，不写入用户的书源库。测试在临时/内存存储中运行。

## 修改前计划

1. 枚举有效书源JSON并逐文件测读取、UTF8/JSON解码、结构转换、兼容检查、去重预览、完整后台导入；使用真实结果决定性能修改，不仅复述合成基准。
2. 整理入口改为完整工作面板：已有书源数量、明确整理范围、本地重复整理、联网体检、最近结果与可恢复的进度。沿用Material3主题、字体、16px边距，不增加视觉噪声或新依赖。
3. 体检状态区分运行、停止中、已停止、失败、完成；保留真实已检查/总数，支持继续未完成项、重试问题项；关闭进度仍可后台运行。
4. 结果审查提供状态分类、搜索、单项原因和选择计数；部分可用/缺发现能力/超时不默认停用，避免“一次不完整检查就批量停用”。执行前只作用于仍存在且启用的选中源，保留未处理结果。
5. 重复整理在后台完成候选准备与分析，显示忙碌/失败状态并防止重复启动；核查保留建议和同站点变体处理。书架关联与存储并发边界按代码事实决定最小修复。
6. 先新增/运行行为回归再调整；每次视觉迭代前做实际渲染检查，窄屏/大字体/暗色/空/部分取消/失败/结果均需验证。相关Flutter状态测试按独立进程运行，最终回测真实语料并记录数据、变更文件与未覆盖边界。

## 分工

主线程：整理UI、路由整合、本地化、基于真实热点的导入优化和总验证。
子任务：真实资源基准；整理逻辑只读审查，之后分配独立后端修复。

## 已实现的结果

### 真实导入性能

- 对用户目录中的 11 个书源 JSON（合计 51.6 MiB）运行了解析、预览、转换、保存、重新加载一致性测试；替换规则目录不是书源，单独排除。
- 最大文件为 25,757,012 字节、4,513 条数组记录，生成 4,512 个有效候选，默认选中 3,832 个。Mac 上 Flutter test JIT 单文件独立进程中，后台分析约 488.5 ms，纯查重约 17.1 ms；没有复现本地文件一直卡在解析的现象。
- 确认耗时热点是保存前重复的对象/Map 转换。删除 worker 的 `toJson` 与主 isolate 的 `fromJson` 往返，并缓存每个配置的 base URI：最大文件转换从 2120.2 ms 降为 70.2–98.4 ms。另一份 22 MB 文件从 1134.6 ms 降至 69.9 ms。
- 大书源库后台加载也直接返回类型化列表，最大语料重新加载从 2810.3 ms 降至 2086.3 ms。保留现有损坏记录隔离、兼容性检查及排序；没有引入版本缓存或依赖。
- 导入提交使用批量保存返回的列表，无需立刻重读刚保存的书源库。上面独立测量的阶段有重叠，不能相加宣称为用户实际等待总时长。
- 延续已移除的 64 MiB 文件硬限制和默认 10,000 条数量上限。测试仍保留调用方显式指定解析数量限制的行为。
- 参考 Legado 的 `ImportBookSourceViewModel.kt`：其后台导入主要是 JSON 转实体、按 source URL 查询已存记录和更新时间比较，不会在导入时执行联网健康检查。本项目同样把联网体检留在整理操作中。

可复现脚本：`tool/benchmark_real_source_import.dart`。原始阶段测量保存在 `.omx/real-source-import/`，不将用户语料复制进仓库。

### 书源整理

- 入口显示已启用、全部、当前选中三种范围及确切数量；提供本地重复整理和联网体检。
- 检查运行、停止中、停止、失败、完成分别显示；保留原分母与实际完成数，支持后台继续、恢复剩余项、重试问题项。应用级 coordinator 确保退出管理页不会取消任务。
- 结果区分可用、部分可用、检测失败、连接超时、待确认，支持名称/地址搜索和筛选。默认不勾选停用，书架在用源有标记，明确失败项快捷选择避开在用源。
- 体检保存仅合并健康证据，重新核对当前执行配置；用户在检查期间改名、分组、停用、修改规则或删除源时，不会被旧快照覆盖或复活。
- 重复分析把候选整理放入后台，在库变更时重新分析；同站不同规则保留人工判断。推荐保留考虑书架引用，停用操作只作用于当前仍存在且启用的源。
- 重复组展平成按需构建的列表，覆盖单组 600 个候选，只创建可见行；结果页同样使用 sliver 延迟构建。

### 主要文件与简化

- `source_import_service.dart`、`source_config.dart`、`book_source_registry.dart`：去掉重复序列化/重建，减少大对象临时分配。
- `book_source_maintenance_coordinator.dart`、`book_source_health_check_service.dart`、`book_source_maintenance_assessment.dart`、`book_source_health_configuration.dart`：可恢复任务、分类和并发健康证据校验。
- `book_source_management_page.dart`、`book_source_management_maintenance.dart`、`book_source_management_controller.dart`：路由、后台查重和安全应用结果；独立路由 part 缩小页面职责。
- `book_source_maintenance_sheet.dart`、`book_source_maintenance_progress_sheet.dart`、`book_source_cleanup_review_sheet.dart`、`book_source_dedupe_review_sheet.dart`：整理入口、进度及审查界面。
- `book_source_usage_service.dart`、`main.dart`、四种语言 ARB：书架引用查询、应用级任务生命周期和文案。
