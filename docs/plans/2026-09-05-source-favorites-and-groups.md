# 书源收藏与自建分组

状态：已按用户批准方案实现，自动化回归与界面截图验收通过。

## 用户交互

- 发现页两种布局共用“全部 / 收藏 / 分组”范围；分组可搜索，长名称省略，列表布局的范围栏和搜索框固定。
- 书源标题旁星标一键收藏，更多菜单可加入分组或查看来源详情；聚合最新列表的来源名称可点开来源操作。
- 收藏保留当前浏览内容、已展开频道和滚动位置；取消收藏提示可撤销，来源卡片消失后撤销仍有效。
- 单个书源可以属于多个分组。编辑面板支持搜索、当场新建、自动勾选、完成保存和取消。
- 批量编辑显示部分选中的混合状态，只修改用户触及的分组，不覆盖其他归属。
- 管理页支持空分组新建、改名、排序、删除、收藏筛选与批量归类。删除分组不删除书源，不改变启用状态。
- 发现页仅浏览已启用并具有对应能力的书源；空状态说明当前无可浏览的来源。

## 保存和兼容

- 收藏使用独立 `isFavorite` 字段；用户分组使用顶层 `groups`，与启用、校验状态分离。
- 未设置顶层 groups 时兼容旧 bookSourceGroup；显式空列表表示主动清空，不能再次恢复导入标签。
- 同源重新导入和刷新保留用户收藏、分组及既有身份；同步接收按现有冲突规则接受远端 winner。
- 注册表兼容原数组格式，并用 v2 容器保存有序分组目录，支持空分组。
- 大注册表的分组读取与运行配置比较在后台执行；组织元数据变化只失效新增来源涉及的内容缓存。
- 公开 ORSP 来源的收藏与成员分组随现有 WebDAV 书源同步。兼容/私人书源的既有同步限制保持；空分组目录和排序仅保存在本机。
