# 听书设置弹层精简

用户已授权直接重做系统与云端两种设置状态。基于已有独立播放器，弹层只负责声音设置。

- 删除弹层中的章节、句子、进度、播放状态、播放控制和重复音量；播放器保持现有能力。
- 保留语速（播放器按钮实际指向这里）、系统音色与音调、云端配置专页入口、定时设置（播放器定时按钮实际指向这里）。云端不显示不支持的音调。
- 复用 ReaderThemePalette：日间弹层 #F7F7F8、正文 #202124、次要文字 #666A70、强调 #3F63B8、控件填充 #E8EAED；不新增颜色或字体系统。标题 titleLarge、设置 bodyMedium、数值 labelLarge，20px边距、16px组间距、轻填充分段选择。
- 结构：标题/关闭 → 引擎切换 → 音色或云端配置 → 语速/系统音调 → 单行定时。去掉卡片嵌卡片和横向三列滑条，标签/数值同行，滑条独占下一行。
- 验证已有独立widget测试基线，再覆盖两种引擎的配置入口、滑条、定时与重复内容移除；真实Flutter截图检查手机和深色大字号。

设计检查：这是现有播放器的附属设置，不需要第二套视觉主题、播放器或大状态卡。结构强调所选音源与它真正支持的控制。
