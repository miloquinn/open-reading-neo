# 书籍详情页

## 页面与交互

发现页（卡片、列表、平板布局）和搜索结果共用 `SourcedBookActions.showBookDetails`，进入独立详情页。复用 `FloatingSubpageScaffold`、主题字体/配色、书籍封面、书架服务和下载控制器。

- 封面与书名、作者、书源并列，分类和连载状态按书源实际返回展示；下方为可选择的简介、最新章节和更新时间。
- 手机内容边距 24px，桌面内容宽度限制为 752px。窄屏和大字号将封面信息纵向排列；底部「加入书架」「阅读」始终左右等宽并排，文字可换行且按钮保持等高。
- 「阅读」「加入书架」固定在安全区内；加入书架直接保存在线书，成功后留在当前页并显示「已在书架」。保存失败在按钮上方提供重试。
- 阅读器压入详情页之上，返回后恢复详情页操作，并重新读取书架状态。
- 下载本地入口放在详情内容下方，复用章节下载、进度、取消、失败重试和后台继续。取消状态可以收起，下载完成不自动退出详情页。下载期间禁用阅读与重复操作，避免并发下载建库丢失阅读位置。
- 详情读取期间先展示发现/搜索摘要，失败可重试；不完整的详情响应保留已有元数据。
- 不新增依赖。旧详情面板保留兼容入口，现有发现/搜索导航统一使用新页面。

## 验证

- 控制器测试覆盖详情合并、失败重试、书架状态、重复提交、下载及销毁后的异步回调。
- 新详情页 widget 测试覆盖加载失败、反复进出阅读器、提交中防重、下载取消与收起，以及 390px、320px、1100px 和深色 1.6 倍字号。
- 发现入口、加入书架、已在书架、保存失败重试、后台下载、阅读转场与返回通过独立测试进程验证。
- 可使用 `DETAILS_PREVIEW_DIR=output/book-details flutter test test/sourced_book_details_page_test.dart` 生成真实 Flutter 布局截图（字体加载路径为本机 macOS 预览环境）。生成封面的自绘文字使用系统默认字体，widget 测试引擎可能显示方框；正文、按钮和布局检查仍有效。
- 发现页合并运行有既有的进程全局状态污染：首条后多条 `pumpAndSettle` 超时，相同用例独立运行通过。保留断言并分别运行，不归类为产品构建失败。
- 尚未验证真机手势、真实书源网络下载及完整平台打包。全仓静态检查发现其他并行改动的告警；本次详情相关文件单独静态检查通过。
