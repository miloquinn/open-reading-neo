# 统一锚定菜单与连续变形

用户要求：复用书源管理已有玻璃菜单，替换默认更多菜单及截图中的音色选择；圆形按钮连续展开为圆角矩形，关闭反向收回。

执行顺序：先运行已有菜单回归；抽出共享菜单路由，保留选项、禁用、分组与回调；迁移入口；添加动画几何、取消、边缘、长列表与减少动态效果测试；独立运行受影响页面测试并检查真实渲染。

组件：`app_menu.dart` 持有唯一表面和动画，旧 `FloatingSubpageMenuButton` 保留兼容封装。菜单在按钮位置展开，宽高裁切边界和圆角使用同一条无回弹曲线；图标淡出、条目稍后淡入，关闭完成后触发业务动作。保持安全区、主题、键盘退出、焦点和大字号可达。

范围：操作型弹出菜单及听书音色选择。AI 协议、书源类型等编辑表单的下拉框不在此次迁移范围。保留工作区既有未提交修改，不增加依赖。
