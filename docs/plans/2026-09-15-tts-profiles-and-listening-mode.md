# 多语音配置、试听与听书入口

## 交付行为

- 云端 TTS 支持命名、添加、编辑、删除多套 OpenAI 兼容配置，每套分别保存地址、模型、音色、格式、回退偏好和安全存储中的 API Key。保留至少一套配置。旧单配置以默认条目继续使用原来的密钥，无需重新填写。
- 配置页可试听当前草稿，统一短文使用当前听书语速；试听前暂停书籍，试听不会写配置、改变书籍位置或在失败时回退到另一种声音。停止、切换草稿和离开页面会使未完成的试听失效。新配置不会借用旧配置的密钥。
- 「保存并使用」保存草稿、选中该配置并启用云端引擎。听书设置提供已保存语音的快捷选择，播放中切换会从当前位置继续。
- 语速滑条原本已支持最高 2×，此次新增 1×、1.5×、2× 快捷按钮，并验证云端合成参数及缓存随语速变化。
- 「听书设置」顶部新增「使用独立听书页面」开关。默认开启，关闭后点击阅读器听书按钮展开底部控制菜单。本地书与在线书共用偏好，重启保留。
- 底部菜单复用完整播放器的章节、前后句、播放/暂停、音量、语速和引擎控制；关闭菜单继续播放，「结束听书」停止。可从菜单打开完整播放器，保持已暂停或正在播放的状态。

## 设计与范围

复用阅读主题、共享锚定菜单、设置子页面和现有播放器组件。手机底部菜单最大占屏幕高度的 72%，短屏和大字号允许滚动。配置页保持固定保存按钮，已保存语音位于顶部可展开列表，试听靠近音色字段。

支持的是多套 OpenAI 兼容语音接口，不包含其他厂商的专有协议适配，也不内置公共 API Key。服务商和音色由用户填写；本轮未请求真实付费服务。
