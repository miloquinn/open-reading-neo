# 书库更新与本地 TXT 绑定书源

## 用户流程

- 书库不增加顶部入口或说明条。有更新时，仅在该书封面右上角显示 18px 小图标；封面网格、卡片与列表保持一致，正文区域不增加更新标签。检查更新入口保留在书籍设置和详情页。
- 应用打开并加载书库后自动检查，随后每 30 分钟检查一次；回到前台也检查到期记录。每本书只允许一个并行检查，手动检查不受频率限制。
- 书籍设置和书库详情共用更新卡片：检查更新、状态、最新章节、上次检查时间、上次更新时间。信息按钮解释检查频率、时间来源和本地续更规则。
- 在线书籍检测到新章后，阅读器使用新目录；只有加载了对应目录才清除更新标记。
- 本地 TXT 可以搜索、绑定或更换书源，补充书源封面（保留自定义封面）。绑定保留原文与阅读位置。
- 本地正文由用户点击“下载新章节”后加入现有下载队列。首次绑定、换源或章节对应关系失效时，先确认本地已有的最后一章。已下载正文修订沿用原有冲突比较流程。

## 数据和一致性

`SourceBookUpdateInfo` 记录检查状态、检查时间、源更新时间/首次发现新章时间、最新章 ID/名称和新章数。数据存入已有 `source_book_json` 的 `_openReadingUpdates` 字段，不侵入书源变量，不要求数据库结构迁移。旧书籍缺少字段时显示“尚未检查”；没有可靠的更新时间时明确显示暂无记录。

`BookDao.updateSourceBookMetadata` 仅按 ID、源 ID、源书籍 ID 和原元数据进行条件更新。检查结果不会覆盖并发阅读进度、自定义封面、下载或换源结果；条件写入同时核对正文版本和存储类型。绑定通过独立事务只更新书源字段，保留书源请求期间变化的本地进度和自定义封面。

检查只获取目录，不下载正文。目录检查强制刷新，同时更新阅读目录缓存。失败保留最后已知的章节和更新时间，以及尚未处理的新章封面标记。后台追加成功立即持久化最新章节和状态；已打开的详情页监听书库变化刷新。在线以目录尾章记录新增；本地以实际下载状态的完整 ID 前缀核对，缺少对应关系时不自动拼接。

续更拼接以持久化的旧章节边界保留原文，不用新章节列表验证旧文件。支持 UTF-8、GBK、UTF-16（含无 BOM）本地 TXT，续更统一写为 UTF-8，原文件沿用 TXT 修订历史保存。解码出现替换字符时停止写入。

## 验证

核心回归覆盖新增/重复检查、时间来源、失败重试状态、手动检查和自动节流、换源竞态、条件写入、连续追加以及本地编码。控件测试独立运行，覆盖详情入口、提示弹窗、窄屏/大字体和下载任务。另验在线阅读、换源、目录缓存和书库平板布局。

本地 macOS 普通构建受开发证书配置限制；可用 `xcodebuild ... CODE_SIGNING_ALLOWED=NO CODE_SIGNING_REQUIRED=NO build` 检查未签名产品。真实线上书源与 iOS/Android 物理设备仍需设备验收。
