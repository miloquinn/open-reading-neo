# 正文片段编辑设计草案

- 状态：Superseded draft。用户已收敛首期到TXT，并要求同步真实云端文件；当前设计见 `txt-editing-webdav-sync-design.md`。本文的在线书首期、本机覆盖及暂不改文件策略不再适用，以下仅保留为先前方案记录。
- 日期：2026-09-05。
- 需求来源：飞书「问题反馈」第 10 行「加一个可编辑文本的功能」，以及本次用户提出的先设计、再对照要求。
- 现状依据：当前工作区与 v2.6.4；自动翻页已有未提交实现，接入时须兼容，不能覆盖其他工作。
- 设计约束：沿用根目录 `DESIGN.md` 的本地优先、状态明确、复用现有主题与控件原则。

## 结论与工作量

建议第一版实现「选中片段 → 编辑正文 → 保存 → 返回原阅读位置」，满足错字纠正、删掉一段广告、补写遗漏文字。只影响当前书籍、当前章节、当前设备；保留书籍文件和在线原文。

编辑界面本身工作量较小；可靠的第一版属于中等规模改动，因为需要章节版本、持久化、选区映射、批注解析和缓存一致性。若首期包括整章自由改写、跨格式原文件导出、正文修改同步，规模与风险明显增加。本文不承诺未经实现验证的工期。

## 与已存在功能对照

| 已有能力 | 本功能的关系 |
| --- | --- |
| 长按选字、复制、批注、搜索 | 复用选区及菜单；增加「编辑正文」动作 |
| 替换净化规则 | 适合重复模式批量处理；正文编辑精确作用于当前选中的一处，不生成全书替换规则 |
| 本地/在线共用文字排版 | 两个入口接同一修改存储与投影逻辑，不各写一套规则 |
| 阅读位置、笔记、高亮 | 保留旧锚点，新增版本感知解析；不能改字符串后继续直接使用旧数字位置 |
| WebDAV 笔记与进度同步 | 现有同步必须能区分修改依赖，避免把本机修改后的坐标发送到原文设备 |

## 第一版建议范围

| 项目 | 建议 |
| --- | --- |
| 编辑对象 | 同一章内选中的文本片段；可替换、删空、补写和插入换行 |
| 第一批格式 | 本地 TXT；已加入书架、有稳定书籍/章节身份的在线纯文字书 |
| EPUB | 第二批开放单个文字块内的编辑，须先通过样式、图片及目录锚点验证 |
| PDF、漫画、图片内容 | 不显示正文编辑入口；现有图像页不具备相同文字编辑基础 |
| 整章自由编辑 | 待用户选择；可复用底层版本机制，但大章编辑和定位变换需单独验收 |
| 原文件及导出 | 第一版保留原文件；导出修改版 TXT/EPUB 另行设计 |
| 同步 | 第一版正文修改仅在本机；修改依赖的笔记明确标为仅此设备，原文笔记继续按原设置同步 |
| 恢复 | 编辑框撤销/重做；保存后撤销最近一次修改；本章恢复修改前内容 |

不是所有「走文字阅读器」的格式都自动开放，能力由实际可定位与可重建的章节管线决定。临时在线预览需先加入书架，再编辑。

## 用户操作

1. 长按正文、拖选范围，选文菜单的「更多」中选择「编辑正文」。
2. 手机进入全屏编辑页；平板/桌面使用有最大宽度的编辑窗口。键盘出现后编辑区始终可见。
3. 默认带入所选文字，可修改、删除或补写；「查看修改前内容」折叠展示对照。编辑输入不触发阅读器逐字重排。
4. 点击「保存」，原子写入成功后返回阅读器，重排该章并回到修改位置。提示「已保存」并提供「撤销」。
5. 阅读器更多菜单增加「本章修改」，用于查看修改前/当前内容、撤销最近一次及恢复本章。没有修改时不占用正文常驻空间。

```text
取消                编辑正文                保存
书名 · 章节名

查看修改前内容 ▸

┌────────────────────────────────────────────┐
│ 可编辑的选中文字                           │
│ 支持改字、删除、补写、换行                 │
│                                            │
└────────────────────────────────────────────┘

仅修改本书本章，在此设备保存
```

文字为空表示删除选区，不按“无内容”拒绝保存；没有变更时保存按钮禁用。不允许插入破坏 Unicode 字符边界的片段。选区跨章节不开放。全章删除需要额外确认，并使用明确空章状态，而不能被净化的“非空原文保护”重新填回。

## 交互状态与文案

- 正在保存：禁用重复提交，允许保留编辑内容；成功通知只在事务完成后显示。
- 保存失败：留在编辑页，保留已输入文字，可重试；不得先退出再报错。
- 有未保存修改时返回：保存、放弃修改、继续编辑；正常离开可控制，进程被系统杀死前未保存内容不承诺自动恢复。
- 恢复本章：先说明「将恢复本章修改前内容，保留笔记」，确认后执行；不删除笔记摘录。恢复自身也形成可撤销的版本，不直接销毁旧记录。
- 源内容/净化规则变化：提示「本章原文有更新，你的修改已保留」，可查看对照、继续使用当前修改版本，或明确选择恢复到新的原文。不能按旧位置自动覆盖新内容。
- 笔记原句已被删改：「对应文字已修改」，保留摘录、笔记和管理入口，停止在错误文字上绘制高亮。
- 修改依赖的笔记：「仅此设备」，说明正文修改尚未同步；不改变用户其他同步开关。
- 用当前阅读主题、应用字体和现有确认弹窗；完整本地化，不新增一套颜色或依赖。
- 可访问性：输入、原文展开、保存、撤销有明确语义标签；触屏按钮目标沿用至少 44×44；桌面提供保存及撤销快捷键，组合键不触发阅读翻页。

## 技术设计

### 内容层次必须明确

```text
解析原文 R → 替换净化 → 基文 B → 用户编辑 → 可读文本 E → 排版显示 D
```

当前 `ReaderTextLayout` 只映射排版显示与可读文本，不提供正则净化前后的逆向映射。因此编辑锚定版本化的 B/E，不把显示选区位置当作文件字节位置，也不把正则替换反推成原文坐标。

建议用按章的修改快照加有序替换操作：存储第一次编辑时的 B、当前 E、内容签名和版本；每次保存记录相对于上一版本 E 的确切替换区间、旧文字、新文字。一次事务更新操作记录、当前快照与版本。后续编辑已修改/新增的文字时，使用捕获的当前版本，不靠累加偏移猜测坐标。

保存前检查书籍身份、章节身份、编辑器捕获的内容版本与精确选区文字。发生后台刷新或版本变化时，保留草稿并显示冲突；不静默覆盖。

### 身份、存储与生命周期

- 每条修改关联稳定本地 bookId 和 chapterId；在线书额外保留书源及在线书籍身份，不能按标题或章序匹配。第一版在线编辑要求加入书架。
- 建议记录：基文快照与签名、源内容签名、净化规则签名、编辑版本/父版本、起止 UTF-16 范围、旧文字、新文字、上下文、时间、当前状态。已有 `CanonicalLocator.contentSignature` 可利用，但相关读写路径需真正接入。
- 沿用现有 SQLite 和迁移机制，新增有书籍外键的章节修改存储；正文修改是用户数据，不能放进可清理的网络/分页缓存。
- 只保存被编辑的章节，不复制整本书；首期保留受控的最近版本和基文，不承诺无限历史。历史保留上限需通过长章性能测试确定。
- 清缓存、重开、重启保留修改；删除书籍沿正常书籍数据删除流程处理。重新导入/换源不按同名书自动继承修改。
- 首期不自动将本地修改加入现有书籍文件同步或阅读数据导出。相关产品说明需明确，后续备份与跨设备能力单独评估。

### 批注和进度

必须新增 B↔E 的区间投影和版本感知解析；不是直接修改已同步的笔记 offsets。

- 与修改互不相交的旧批注，保持原始锚点，在渲染时投影到 E；恢复时可以回到原定位。
- 被替换/删除的旧批注保留摘录与笔记；没有精确映射时置为不可定位，不把位置按比例硬塞到新文字。
- 对新插入文字的批注需要编辑身份、版本及局部范围；未具备该版本的设备不能假装精确定位。
- 第一版将依赖本地编辑的新增批注留在本机；同步过滤需覆盖扫描、已排队批次、导出和重试路径，不能仅隐藏开关。可以映射到基文的笔记仍照常同步。
- 保存前捕获阅读锚点；保存后回到编辑起点或最近可映射的内容边界。页码变化正常，不能回到书籍第一页。
- 现有跨设备进度使用可解释的基文锚点；无法映射的插入位置仅本地精确恢复，对外使用明确的章节/基文边界降级。
- 多次编辑、重复文本、新增文字再编辑、撤销、重开和已有净化规则组合，必须用操作序列验证，不能只有固定字符串示例。

### 源更新与恢复

基文源/规则签名相同才按现有版本应用修改。签名变化后保留原 B、编辑 E 和修改记录，继续展示明确标识的修改版本，等待用户对照；不自动迁移，不悄悄换回新原文。

「恢复修改前内容」恢复第一次修改时的净化后 B，仍不是原文件字节；存在新基文时，对照界面另提供「使用更新后的原文」。两个动作的预览与含义必须区分。规则变化后的重新应用需生成新基文版本，首期不尝试自动跨版本合并。

### 缓存与阅读功能一致性

文本、分页、滚动分段、翻页截图、搜索文档、朗读分句都消费同一 E 内容版本。把最终内容签名/编辑版本纳入相应缓存键，仅使受影响章节的派生数据失效；不整书重解析。

打开编辑器时暂停朗读、自动翻页和正在进行的手势。保存后保持暂停，由用户明确继续，避免操作中读到旧文字。后台预取、异步净化和分页返回时检查版本，丢弃旧结果；不会覆盖刚保存的修改。

### EPUB 后续门槛

现有章节包含带样式的文字块、图片块和解析期目录锚点。EPUB 开放前应支持单块内编辑后的块坐标与目录锚点投影；新文字继承所在块样式，图片顺序不变。跨图片/跨块/跨章节修改首期不开放。不能把 EPUB 全章替换成纯文本以换取表面可编辑。

## 实施与验收顺序

1. 先建立内容版本、区间投影、保存/恢复事务的核心测试，锁定净化、Unicode 和重复编辑语义。
2. 接入 TXT 单章局部编辑及手机/桌面编辑页，验证原文件字节不变。
3. 完成批注/进度版本解析、搜索/朗读/分页一致性与同步过滤，再接在线纯文字书。
4. 原设备验证阅读、后台、键盘、缓存清理和源内容更新，之后才将功能标记完成。
5. EPUB 单块、整章编辑、修改版导出和正文同步各自扩展验收，不混入第一版承诺。

发布前至少覆盖：

- 中文、emoji、组合字符、CRLF、空行、净化开启；重复句子只修改所选一处。
- 改长、改短、删空、再次编辑新文字、撤销后继续编辑、重开恢复。
- 插入文字前后笔记正确；重叠笔记保留且不误定位；还原后能够恢复可映射笔记。
- 保存失败、重复保存、编辑中章节更新、晚返回的预取/分页结果不破坏已保存数据。
- 搜索、复制、朗读、各种翻页模式读取同一版本，重新打开停留在合理位置。
- 清缓存不丢修改，原文件哈希不变，未编辑章节不会获得用户修改。
- WebDAV 开启后不发送依赖本机修改的裸坐标，已有原文笔记及未启用同步的范围行为保持原样。
- 大章节仅处理该章；编辑输入不卡顿，保存不在 UI 主线程做整书计算。
