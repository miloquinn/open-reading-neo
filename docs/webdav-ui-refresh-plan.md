# WebDAV 页面优化计划

2026-09-05，本轮在已完成的详细错误诊断基础上调整 UI。

视觉方向：沿用应用字体、主题色和 Material 3 表面层级，压缩重复卡片，突出真实同步状态与操作，错误信息完整且可复制。

内容顺序：同步状态与立即同步 → 阅读位置/正文分项状态 → 当前错误详情（有错误时）→ 跨设备续读设置 → 书籍/同步范围/连接入口 → 本机配置清除与说明。宽屏左右分配“状态”和“管理”，最大宽度 1080，手机保持单列。

交互：按钮原位显示同步阶段；循环进度遵从减少动态效果设置；保持 Material 触摸/悬停/焦点反馈；诊断内容保留选择复制并提供一键复制。未配置、进行中、部分失败、暗色与放大文字均验证。

实现边界：只调整同步页面和对应文案/测试，不改同步算法和网络请求；复用当前布局工具，不增加依赖。保留此前未提交的协议与状态修复以及用户 coverage 目录。

执行次序：
1. 运行既有页面测试并渲染基线截图，确认交互已有保护。
2. 增加主操作可见性、文件同步进行中、完整范围摘要、大字号和窄屏错误状态回归。
3. 概览页合并同类入口、删除重复活动说明，诊断独立分区。
4. 连接页与同步范围页同步调整分组、字段和间距。
5. 渲染手机/桌面、正常/失败/暗色截图，每次修改前记录截图判定；执行页面测试、相关控制器回归、完整静态分析。
