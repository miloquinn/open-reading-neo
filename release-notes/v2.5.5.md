# v2.5.5 Release Notes

## 🐛 Bug Fixes

### Fixed horizontal page turn flicker at chapter boundaries

**Issue**: When using horizontal slide page mode, turning pages at chapter boundaries caused a brief (~0.1 second) flicker where the wrong page would flash on screen before settling on the correct page. This affected both forward and backward page turns, and occasionally caused pages to become stuck at chapter boundaries.

**Root Cause**: The chapter window adjustment logic (forward contraction and backward expansion) was executing during scroll animations. This caused the underlying page list to change while the PageView was still animating, invalidating the PageController's position index and triggering corrective jumps that manifested as visual flickers.

**Solution**: Added `isScrollingNotifier.value` check to ensure window adjustments only execute after scroll animations have completely stopped. This keeps the page list stable during user gestures, eliminating the flicker.

**Impact**: 
- ✅ Smooth, flicker-free chapter boundary transitions
- ✅ No more stuck pages at chapter boundaries
- ✅ Improved reading experience in horizontal slide mode
- ✅ Affects both TXT and EPUB formats

## Technical Details

- **Modified**: `lib/pages/reader/native_reader_page.dart`
- **Key Change**: Defer `_commitHorizontalForwardContraction` and `_commitHorizontalBackwardExpansion` until `isScrolling=false`
- **Testing**: Verified on Android with multi-chapter books in horizontal slide page mode
