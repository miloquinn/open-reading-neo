# v2.5.7 Release Notes

## Bug Fixes

### Show actionable registration errors

**Issue**: Registration failures caused by server-side input validation could be displayed as "Unable to connect to account service, please check your network and try again." This made expired verification codes and invalid registration fields appear to be connectivity problems.

**Solution**:

- Recognize the account service's `422` validation response format.
- Show field-specific guidance for email addresses, usernames, passwords, and verification codes.
- Keep a clear generic validation message for new server-side fields that are not yet recognized by the client.

**Impact**:

- Users can distinguish a real connection failure from an invalid or expired verification code.
- Registration validation failures now explain what must be corrected before retrying.
