# v2.5.9 Release Notes

## Book Source Maintenance

- Added source health checks covering search, details, catalogs, and chapter content, with background progress and result review.
- Added duplicate detection for imports and installed sources with exact, normalized-address, and same-site review modes.
- Duplicate cleanup disables selected sources by default and never deletes their configurations.
- Refined source import analysis, management actions, and protocol and content-rights information.

## Account Reliability

- Fixed browser-based GitHub and provider login briefly reporting an account-service network failure after returning to the app even though authorization completed moments later.
- Browser authorization now silently retries transient connection changes while preserving real expiry, rejection, and server errors.
- Supplementary membership, referral, and security data no longer invalidate an already successful account session.

## Performance and Recovery

- Added an indexed lookup for book annotations and prevented duplicate text-note writes.
- Added one-shot cache eviction and retry when account avatars or source covers fail to decode.
- Calculated file hashes while copying large imports to avoid a second full disk read.
- Improved recovery from invalid account summaries, custom reader themes, update checks, and cached image failures.

## Interface Improvements

- Made Discover source lists, paginated results, and category expansion smoother while preserving directory scroll position.
- Refined App and reader font selection, online-font progress updates, and safe fallback from damaged custom themes.
- Improved floating subpage layout behavior across compact and expanded screens.
