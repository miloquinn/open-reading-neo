# v2.5.9 Release Notes

## Discover Page

### Smoother source-list browsing

- Added lightweight entrance motion for source rows and newly loaded books in the Discover page's list layout.
- Source categories now expand and collapse smoothly instead of appearing abruptly.
- Large category sets are built lazily, and collapsed content releases its hidden widgets and animation resources.
- Selecting a category now starts the result view below the top bar, while returning to the source directory restores the previous scroll position.
- Moved the interactive scrollbar below the top bar and above the floating navigation so its full track remains reachable.

## Font Experience

### Refined font selection and download feedback

- Moved App and reader font selection into a focused settings component.
- Unified system, downloadable, and imported font states in one consistent interface.
- Kept online font progress updates local to the font list and throttled network progress events, avoiding repeated rebuilds of the full Settings page and application root.
- Improved diagnostics for unreadable font manifests, failed runtime registration, and temporary-file cleanup while preserving the safe fallback to the system font.

## Performance

### Reduced disk I/O during large book imports

- The managed copy now calculates its MD5 digest while streaming the source file to disk.
- The copied file no longer needs a second full read for integrity verification.
- Content-hash verification and rollback guarantees remain in place.

## Architecture and Reliability

- Separated EPUB metadata contracts and parsing from the book import orchestrator.
- Split font selection and community mark rendering out of the oversized Settings page.
- Cleanup failures can no longer replace the original import or download error.
- Added regression coverage for large-file copy integrity, font selection behavior, and local online-font progress updates.
