# v2.6.0 Release Notes

## Background Read Aloud

- Moved the active read-aloud state into an app-level session so playback can retain its book, chapter, and sentence position when the reader route closes or another app is opened.
- Queued adjacent sentences through system TTS to reduce gaps while keeping sentence highlighting, pause and resume, and saved progress aligned with the spoken segment.
- Added an iOS spoken-audio session, Now Playing metadata, lock-screen and Control Center commands, and interruption handling for calls and audio-route changes.
- Unified Android media notifications and headset keys with iOS remote controls through one playback-control protocol.

## Tablet Page Curl

- Anchored both leaves of a two-page spread to the true center binding while preserving the 24px visual gutter as inner paper spacing.
- Kept real reverse-page textures at their normal colors and opacity instead of applying the muted phone-paper highlight.
- Enabled direction-based turns across the entire spread: a left swipe from either leaf advances through the right leaf, while a right swipe from either leaf returns through the left leaf.
- Prevented the exact flat catch-up frame from painting into the sibling leaf and causing an occasional one-frame flash.

## Reading Sources and Discovery

- Reused on-device chapter catalogs and content for compatible reading sources so repeated opens can show cached content immediately and refresh stale entries in the background.
- Isolated caches by source configuration, book variables, authentication state, and login revisions; full-book downloads continue to fetch current content.
- Changed local source-registry read or parse failures into a retryable Discover error state instead of leaving the page loading indefinitely.

## Account Compatibility

- Allowed first-time email-code sessions without a chosen username to use the effective display name or email prefix instead of failing client-side user parsing.

## Privacy and Data Protection

- Disabled ordinary Android application backup so private databases, account state, and reading data are not copied through the platform's general backup and restore channel; explicit in-app synchronization is unaffected.

## Architecture, Cleanup, and Performance

- Removed obsolete reader-level playback controls, duplicate visibility state, and superseded infrastructure now owned by the app-level read-aloud session.
- Split oversized AI, settings, theme, import-metadata, and book-source UI modules into focused internal boundaries with clearer state ownership.
- Reused cached catalogs and chapter content on the immediate reading path while background refreshes, disk writes, and media-state synchronization stay out of the visible-page critical path.
- Added regressions for media sessions, iOS TTS, reading-source caches, Discover recovery, tablet binding alignment, reverse-page colors, whole-spread gestures, and sibling-leaf flashing.
