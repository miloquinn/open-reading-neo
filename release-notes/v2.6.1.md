# v2.6.1 Release Notes

## Online Shelf and Source Compatibility

- Added one validated reconstruction path for online shelf books across Library, Home, and startup resume. Missing, malformed, or identity-mismatched source snapshots are rejected safely instead of being force-unwrapped before navigation.
- Made optional cover, catalog-pagination, and next-page URLs from compatible reading sources degrade safely when they resolve to non-network values, while retaining real book-link fallbacks from result entries.
- Improved compatible script DOM string extraction so multiple selected content fragments are preserved in reading order.
- Persisted remote image URLs and request headers in chapter caches so cached comic chapters can reopen with complete image pages.

## Comics and Image Reading

- Added continuous vertical reading alongside left-to-right and right-to-left paging, with per-book mode persistence; online comics default to vertical reading.
- Kept catalog jumps, visible-page progress, and cross-chapter continuous reading synchronized while releasing chapter content outside the active window.
- Added in-place retry for failed image requests and decodes, including targeted cache eviction before reloading the page.
- Prioritized visible image requests over queued preloads and separated long-lived source image-page storage from cover storage with larger image limits.
- Unified theme-aware controls, jump actions, and settings across comics, image-only source chapters, and PDF pages.

## Large TXT Import

- Limited large-TXT metadata analysis to a file-head sample processed in a background isolate instead of scanning the complete file on the UI isolate.
- Used the filename as the safe title unless the text contains an explicit title or author label, avoiding numeric body lines being mistaken for metadata.
- Lowered the large-TXT segmented-reading threshold to 2 MiB and split oversized unchaptered text into bounded sections for faster opening and pagination.

## Cache and Reliability

- Included source image-page storage in cache usage reporting and cache cleanup.
- Added regressions for online shelf binding validation, source URL fallbacks, cached image metadata, visible-request priority, vertical comic progress, failed-page retry, and oversized TXT splitting.
