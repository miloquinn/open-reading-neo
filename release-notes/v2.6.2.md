# v2.6.2 Release Notes

## Online Sources and Caching

- Added persistent caching for discovery recommendations, categories, and category browsing across ORSP and compatible text/comic sources, with source-revision isolation and invalidation after login, logout, or source refresh.
- Added ETag and Last-Modified conditional revalidation, bounded stale-if-error fallback, concurrent request deduplication, cache quotas, and invalidation guards that prevent obsolete background requests from restoring removed entries.

## Comics and Image Reading

- Improved comic chapter image extraction for multi-value rules, common comic containers, and legacy sources whose content resolves to image pages.
- Stabilized continuous vertical reading across chapter boundaries, active drags, delayed image sizing, empty chapters, and saved progress.
- Added a proper continuous-reading settings sheet and protected asynchronous reading-mode changes from stale callbacks.
- Comic reading remains under active development. Future releases will continue improving compatibility, memory use, and interaction details across more source sites and network conditions.

## Replacement Rules and Reader Reliability

- Moved regular-expression replacement work into asynchronous batches and a killable isolate worker so complex or malformed rules do not block the reading UI.
- Added timeout, invalid-regex, output-expansion, worker-crash, and empty-output safeguards with diagnostics and safe original-text fallback.
- Prepared chapter titles and content before pagination and included replacement-rule revisions in pagination cache identity to prevent stale rendered pages after rule changes.

## Cross-platform Typography

- Unified platform-default reader font resolution across TXT, EPUB, online-source pagination, rendering, previews, and cache identity.
- Uses a sans-serif default on Android, PingFang on Apple platforms, and Microsoft YaHei on Windows while preserving explicit user font choices and embedded EPUB font priority.
