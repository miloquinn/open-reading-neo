# v2.6.3 Release Notes

## Unified Comic and Image Reading

- Unified local CBZ books and online comics behind one reader with shared chapter navigation, progress, retry, reading direction, controls, and cache ownership.
- Fixed reverse scrolling in continuous vertical mode so delayed image layout no longer pulls the reader away from earlier pages or causes repeated jitter.
- Replaced duplicate comic control bars with one compact top and bottom chrome, including a thicker progress rail, larger thumb, and clearer page position.
- Aligned comic reading settings with the text reader design and added persistent Follow system, Light Mode, and Dark Mode options.
- Made vertical, left-to-right, and right-to-left direction changes use the same settings surface and update the active reader immediately.

## Android CBZ Import

- Added CBZ support to Android open, share, and multi-share intents, including common comic archive MIME types.
- Validate that incoming CBZ archives contain supported images before import and materialize a stable app-owned copy that survives upgrades.

## Performance and Memory

- Bound continuous comic data to the active chapter window and release stale page bytes, image decodes, archive handles, and reconstructable caches under memory pressure.
- Pass EPUB and Kindle image bytes directly between parsing and rendering instead of expanding them through Base64 and decoding repeated copies.
- Keep large in-memory documents out of reopen caches while preserving disk-backed pagination and indexed text caches.
- Clear reader, source-response, chapter, cover, avatar, and Flutter image caches when the operating system reports memory pressure without discarding user data or the visible page.

## Cleanup and Reliability

- Removed superseded local and online comic hosts, duplicate control implementations, and dormant application services.
- Shared vertical position geometry and reader resource ownership across local and source readers, with focused regressions for imports, cache windows, theme persistence, direction switching, and active-drag stability.
