# v2.6.4 Release Notes

## WebDAV Reading Data Sync

- Added explicit opt-in synchronization for notes, highlights, underlines, and ink annotations while keeping the scope disabled by default and warning that WebDAV metadata is not end-to-end encrypted.
- Preserved stable annotation identities across new and legacy records and resolve aliases by the newest logical clock, preventing deleted notes from returning or older content from winning.
- Expanded field-level reader-setting synchronization to typography, brightness, alignment, margins, themes, page modes, paragraph styling, tap zones, TXT chapter pages, and image backgrounds.
- Synced custom-theme names, colors, opacity, and order without uploading local background-image paths; per-book image direction remains device-local until a safe stable book mapping exists.
- Added separate opt-in synchronization for replacement rules, including patterns, replacement text, scope, enabled state, and order, with live refresh in the running reader process.

## Privacy, Scope, and Recovery

- Made a disabled synchronization scope stop local scanning, remote materialization, pending counts, and future batch publication together so unsent private data cannot leak through a stale batch.
- Persisted validated remote winners before idempotent business-data materialization, allowing interrupted or deferred records to resume before the next local scan.
- Protected malformed local theme and replacement-rule caches from being interpreted as an intentional empty collection and propagated as mass deletions.
- Retained remote records for disabled datasets without applying them locally, then replayed them in version order when the user enables the scope again.
- Added strict outbound allowlists for public ORSP sources and online-book snapshots. Executable compatible-source configuration, request headers, login data, runtime variables, and source identities containing URL credentials or query data remain local.
- Secrets written by an older release into immutable WebDAV history cannot be erased by this update; affected users should rotate credentials and replace or clear the remote sync directory before reconnecting every device.

## Desktop Reading Experience

- Added page navigation with arrow keys, Page Up, Page Down, Space, and Shift+Space in native and online-source text readers while leaving modified shortcuts to the focused control or operating system.
- Added mouse-wheel and trackpad page turns in paged modes with gesture locking so one continuous scroll stream turns only one page.
- Kept vertical readers on native continuous pointer scrolling while allowing keyboard navigation to move smoothly by one viewport.
- Added mouse dragging and vertical-wheel scrolling to horizontal theme strips while preserving compact theme-card configuration used by the comic reader.
